# Tier-0 Procedural Sound Implementation Plan

**Goal:** Provide useful local ambience and sparse SFX without uploads, network access, model
weights, or license ambiguity.

**Architecture:** Ship a tagged bank of project-authored CC0 recipes for common beds and one-shots.
A deterministic resolver selects by Jaccard tag match, synthesizes low-level PCM with seeded numpy
DSP, prepares loop boundaries, and stores immutable content-addressed WAVs in the shared local
cache. A project endpoint materializes a normal ambience-asset row pointing at that file, so the
existing cue/mixer path remains unchanged. Model Center reports the bank as bundled and installed.

**Tech Stack:** numpy, stdlib wave, SHA-256 cache keys, existing ambience repository/FastAPI.

2. Implement deterministic wind/rain/room/fire/ocean/forest/urban/crowd and sparse SFX recipes.

4. Expose project materialization through the existing sound-asset response shape.
5. Verify determinism, cache reuse, license provenance, audio health, API behavior, lint, and types.
