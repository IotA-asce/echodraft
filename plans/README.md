# Execution Plans

This directory contains delivery sequencing for the `echodraft` MVP and its later platform evolution.

## Reading order
1. [foundation-sprint-plan.md](foundation-sprint-plan.md)
2. [backlog-seed.md](backlog-seed.md)
3. [mvp-execution-plan.md](mvp-execution-plan.md)
4. [phase-roadmap.md](phase-roadmap.md)

## How to use these plans
- Start with the foundation sprint when bootstrapping the repo.
- Use the backlog seed for the first implementation tickets and dependency order.
- Use the MVP execution plan as the master sprint sequence through alpha hardening.
- Use the phase roadmap when deciding whether a request belongs to MVP or later platform work.
